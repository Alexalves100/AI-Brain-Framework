# Brain Project Template

**Version:** 1.0.0 | **Status:** Official

Template para novos projetos com **cérebro digital** baseado no AI-Brain-Framework.

---

## Uso

```bash
# Copiar template
cp -r brain-project-template/ my-new-project/
cd my-new-project/

# Instalar dependências
pip install ai-brain-framework

# Rodar exemplo
python app.py
```

---

## Estrutura

```
brain-project-template/
├── .ai/                    # Cérebro digital do projeto
│   ├── AGENTS.md           # Agentes do projeto
│   ├── memory/             # Memória persistente
│   ├── policies/           # Políticas locais
│   └── skills/             # Skills específicas do projeto
├── app.py                  # Aplicação principal
├── config.py               # Configurações
├── tests/                  # Testes
├── docs/                   # Documentação
└── README.md               # Este arquivo
```
