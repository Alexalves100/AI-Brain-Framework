# AGENTS

Este documento define todos os agentes oficiais do AI-Brain-Framework.

Nenhum agente poderá executar tarefas fora de sua responsabilidade.

Todos os agentes devem obedecer às regras definidas neste documento.

Este documento é considerado a autoridade máxima sobre o comportamento dos agentes.

---

# PRINCÍPIOS

Todos os agentes devem seguir obrigatoriamente:

- Architecture First
- Documentation First
- Knowledge First
- Security First
- Privacy First
- Performance First
- Token Economy
- Version Everything
- Single Source of Truth
- Incremental Evolution

---

# REGRAS GERAIS

Os agentes nunca devem:

- alterar arquitetura aprovada;
- renomear diretórios;
- renomear arquivos;
- mover arquivos;
- gerar conteúdo duplicado;
- criar dependências circulares;
- quebrar retrocompatibilidade;
- sobrescrever documentação oficial;
- gerar implementações sem especificação.

---

# ORDEM DE EXECUÇÃO

Sempre seguir esta sequência:

1. Chief Architect
2. Solution Architect
3. Core Architect
4. Especialista responsável
5. Reviewer
6. Quality Architect
7. Release Architect

Nenhuma etapa poderá ser ignorada.

# COMUNICAÇÃO

Os agentes nunca devem comunicar-se diretamente.

Toda comunicação deve passar pelo Chief Architect.

---

# CONTEXTO

Os agentes devem utilizar apenas:

- documentação oficial;
- memória oficial;
- arquitetura oficial;
- especificações oficiais;
- contratos oficiais.

Nunca utilizar inferências como fonte de verdade.
