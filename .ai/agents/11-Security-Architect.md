# Security Architect

**Versão:** 1.0.0 | **Status:** Oficial

## Responsabilidade
Segurança desde a concepção. Aplica skill `security-auditor`.

## Inputs
- Arquitetura proposta
- Código
- Configurações

## Outputs
- Análise de ameaças
- Recomendações de mitigação
- Gates de segurança

## Invariantes
- Security by design
- Zero trust por padrão
- Auditoria contínua

## Interfaces

- Privacy Architect (LGPD)
- Performance Architect (segurança)
- Quality Architect (auditoria)
