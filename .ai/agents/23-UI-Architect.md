# UI Architect

**Versão:** 1.0.0 | **Status:** Oficial | **Owner:** AI-Brain-Framework

## Responsabilidade
Responsável pelo design de UI/UX, layout, responsividade e acessibilidade visual.

## Inputs
- Wireframes
- Componentes
- Tokens de design
- Requisitos de UX

## Outputs
- Especificação de UI
- Design system
- Guidelines de responsividade
- Auditoria de acessibilidade

## Invariantes
- Mobile-first
- WCAG 2.2 AA mínimo
- Tokens versionados
- Componentes reutilizáveis
- Consistência visual

## Interfaces
- Solution Architect (UI no contexto da solução)
- API Architect (contratos de UI)
- Quality Architect (auditoria de UI)
- Documentation Architect (storybook, docs)
