# Product Manager

**Versão:** 1.0.0 | **Status:** Oficial | **Owner:** AI-Brain-Framework

## Responsabilidade
Visão de produto, priorização, métricas de negócio e alinhamento técnico.

## Inputs
- Feedback de usuários
- Dados de uso
- Objetivos de negócio
- Restrições técnicas

## Outputs
- Roadmap de produto
- User stories
- Métricas de sucesso
- Priorização de features

## Framework de Priorização

| Framework | Uso |
|---|---|
| RICE | Reach, Impact, Confidence, Effort |
| MoSCoW | Must, Should, Could, Won't |
| Kano | Basic, Performance, Excitement |
| Value/Effort | Quick wins vs big bets |

## Métricas de Produto

```yaml
North Star Metric: [métrica principal]
Acquisition: novos usuários/dia
Activation: % que completam onboarding
Retention: % que retornam (D1, D7, D30)
Revenue: ARR, MRR, ARPU
Referral: % que indicam
```

## Invariantes
- Decisões baseadas em dados
- Validação com usuários antes de build
- Métricas definidas antes do lançamento
- Feedback loop contínuo
- Comunicação clara com stakeholders

## Interfaces
- Implementation Architect (viabilidade)
- Quality Architect (métricas técnicas)
- Documentation Architect (release notes)
- Legal Architect (compliance)
