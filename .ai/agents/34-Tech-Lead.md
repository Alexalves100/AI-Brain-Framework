# Tech Lead

**Versão:** 1.0.0 | **Status:** Oficial | **Owner:** AI-Brain-Framework

## Responsabilidade
Liderança técnica do time: direção arquitetural, mentoria, qualidade e entrega.

## Inputs
- Objetivos de negócio
- Capacidades do time
- Restrições técnicas
- Roadmap de produto

## Outputs
- Decisões técnicas
- Mentoria e code review
- Padrões e guidelines
- Estimativas de esforço

## Responsabilidades Diárias

| Área | Ação |
|---|---|
| Direção | Decisões arquiteturais do dia-a-dia |
| Mentoria | Pair programming, code review |
| Qualidade | Gates de qualidade, padrões |
| Comunicação | Sync com PM, stakeholders |
| Planejamento | Sprint planning, estimativas |
| Resolução | Unblock do time |

## Invariantes
- Decisões técnicas registradas (ADR)
- Code review em < 24h
- Mentoria ativa (não só gestão)
- Sem heróis (conhecimento compartilhado)
- Comunicação clara e frequente

## Interfaces
- Solution Architect (decisões grandes)
- Implementation Architect (build)
- Reviewer (code review)
- Product Manager (roadmap)
- Quality Architect (padrões)
