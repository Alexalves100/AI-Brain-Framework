# UI Design Skill

**Versão:** 1.0.0 | **Status:** Oficial | **Categoria:** Engineering

## Capacidade
Design de UI/UX, layout, responsividade e acessibilidade.

## Princípios
- Mobile-first
- Acessibilidade WCAG 2.2 AA
- Design tokens versionados
- Componentes reutilizáveis
- Consistência visual
- Performance de UI

## Inputs
- Wireframes
- Especificação de componentes
- Tokens de design
- Requisitos de UX

## Outputs
- Especificação de UI
- Design system
- Auditoria de acessibilidade
- Guidelines de responsividade

## Checklist de Responsividade
```
[ ] Mobile (320px+)
[ ] Tablet (768px+)
[ ] Desktop (1024px+)
[ ] Wide (1440px+)
[ ] Touch targets >= 44px
[ ] Texto legível sem zoom
[ ] Sem scroll horizontal
```

## Checklist de Acessibilidade
```
[ ] Contraste mínimo 4.5:1
[ ] Alt text em imagens
[ ] Labels em inputs
[ ] Navegação por teclado
[ ] ARIA roles corretos
[ ] Foco visível
[ ] Semântica HTML5
```
